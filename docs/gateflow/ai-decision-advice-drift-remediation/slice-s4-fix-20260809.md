## Finding decisions and fixes

### DR-S4-01 - accepted - fixed

The Advice boundary now requires the direct new
`portfolio_distribution_hash` and `fact_registry_hash` fields to be non-empty
before any model call or reuse lookup. A legacy-only `FrozenInputs` object can
still expose its compatibility-derived key through `input_bindings()`, but S4
rejects that object as `unavailable: input_bindings_invalid`; it can no longer
create or reuse a formal v1 Advice result.

Regression coverage exercises both an empty direct PM-distribution hash and an
empty fact-registry hash. Both paths persist a deterministic unavailable result
without calling the model.

### DR-S4-02 - accepted - fixed

The repair loop now marks `repair_attempted=true` only after the second
iteration has passed the shared-deadline check and is about to invoke the model.
If less than one usable second remains, the account returns `timeout`, performs
one total model call and records `repair_attempted=false`.

The normal repair regression still proves two calls receive timeouts derived
from the original single deadline. A new expiry-boundary regression proves the
audit flag reflects the actual provider-call count.

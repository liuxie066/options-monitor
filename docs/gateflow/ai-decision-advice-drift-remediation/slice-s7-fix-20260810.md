### DR-S7-01 — accepted — fixed

The Agent read path now fails closed unless the referenced `advice_id` occurs
exactly once in the same run/account JSONL. It then verifies run, market and
status before validating the complete formal envelope and comparing every
Sell Put / Covered Call decision scope with the Daily Brief projection.

The comparison includes family, symbol, action, baseline candidate, selected
candidate, all three rationale fields and both internal/external reference
lists. Formal decision, selection, zero-candidate, status, reuse and demotion
shapes are validated before any allowlisted action is returned. Duplicate IDs,
projection differences and malformed structures return an unavailable formal
record with an empty formal `actions` list.

Regression coverage includes:

- formal action/selected-candidate disagreement with the Brief;
- duplicate ID where only one row has matching outer identity;
- malformed demotion data that previously could be silently omitted;
- a valid Covered Call scope and selected candidate.

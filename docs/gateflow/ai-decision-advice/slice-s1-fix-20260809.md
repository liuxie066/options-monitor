## Findings and fixes

### DR-S1-01 — DeepSeek Responses 默认 URL 路径 — accepted — 已修复

`DEFAULT_DEEPSEEK_RESPONSES_URL` 误写为 `https://api.deepseek.com/v1/responses`；
DeepSeek base_url 不带 `/v1`（见 `llm_provider_registry.py` 的
`https://api.deepseek.com` 与官方文档）。已改为
`https://api.deepseek.com/responses`；`resolve_deepseek_responses_url` 的既有
测试（`https://api.deepseek.com` → `.../responses`）确认拼接行为一致。

### DR-S1-02 — 空段 `ai_decision_advice: {}` 未走 unknown-key 校验 — accepted — 已修复

`validate_config` 原先仅在段非空时校验；改为 dict 即校验（`_reject_unknown_keys`
对空 dict 安全），错误信息不再依赖段内容。

### DR-S1-03 — 未配置段可能被 system/user 默认复活 — accepted — 已修复（预防）

`yaml_to_market_user_config` 现在显式保证：root 与 market 均未配置
`ai_decision_advice` 时，输出 user config 不含该键，避免未来 defaults/公共
配置中的 enabled 值被 deep merge 复活。新增 3 个 YAML passthrough 测试
（root enabled、market override 关闭、absent 保持 absent）。

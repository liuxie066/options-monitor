# 一次性进程对象诊断已退役

当前源码已移除 trade-intake 的临时对象图采集器、接收入口、heartbeat probe 和 Brief cache 私有诊断快照。该能力用于一次性内存归因，不是业务 heartbeat、告警或持续运行监控合同。

历史实现及其预算、身份与权限约束保留在 Git 历史；既有离线和生产观察原件不删除。100ms 预算内的 partial 结果只能说明已遍历的部分，不能外推全堆、缓存占用或生产收益。

正常 heartbeat 状态、超时与错误、恢复审计、Brief 读取/验证计时均保留。诊断代码退役不改变业务缓存、账本和通知语义，也不改变现有进程或生产环境。旧版本上的诊断环境覆盖、端点和接收器如需撤除，仍须绑定目标、核对归属并经受控运维授权；本次源码修改不执行这些动作。

## Adversarial Review Pass

- **State machine**: confirmed candidate slot rotation只发生在不同 delivery key；相同 key 不重发；ambiguous 不能被覆盖；pending retry 不因新 revision 改写 exact envelope。
- **Idempotency/recovery**: alerted history保存在 identity-level metadata；滚动单槽不删除已确认 identity 的 revision/digest/delivery key/confirmation time。
- **Failure semantics**: strategy exception evidence与正常空 artifacts 分离；失败 family 的 rows 在 assembler 权威边界被清零，而不是依赖 Markdown 或 materializer 成功。
- **Partial availability**: 一个 family 失败不阻断其他 family 的可靠候选；无可靠候选时 fail closed，不写 successful current，不参与新增候选比较。
- **Over-coupling**: 新 artifact 模块只负责 append/read/schema；策略决策仍在 symbol orchestration，通知决策仍在 Daily Brief service/domain，未增加第二套扫描或调度状态机。
- **Semantic ownership drift**: candidate filter trace继续只表达候选过滤；strategy execution failure由独立 artifact 表达；renderer只消费 canonical data gaps，不推断日志或 CSV 文本。
- **User readability**: partial failure只增加一条“某策略扫描异常，本轮结果不完整”，blocked 继续使用短 failure report；未引入内部 revision/digest/error message 泄漏。

## Additional cross-checks

### Hybrid pricing block plus thesis revocation

The revised plan distinguishes a dedicated review decision from a hybrid row. A hybrid preserves `not_evaluable` pricing/action fields while projecting the independent manual-review requirement. This avoids claiming that an unpriced row is a priced review/close.

### Actual close plus thesis revocation

The revised precedence suppresses a duplicate review action when a fee-qualified close already resolves the exposure. Revoked-thesis evidence remains attached, while one source row cannot become both `close_position` and `review_position` in the same brief.

### Combo behavior

Review-required lifecycle evidence blocks synthetic group close advice while preserving valid active leg-level output. No pairing, assignment, or cost basis is invented.

### Implementation boundary

The re-review retested the three failed assumptions from the first review and the full Goal Confirmation boundary:

1. diagnostic evidence gaps are now independent from whether eligibility remains unresolved;

3. candidate completeness has one frozen authority (`scope_results`) and one shared deterministic projection;

## Goal-bound minimal design review

- Every implementation decision maps to a confirmed success signal: date predicate, OpenD distinction, affected-scope
  isolation, strategy parity, partial-universe disclosure, zero-candidate fail closed, or auditability.
- Exact interval validation is the minimum proof required before treating missing events as authoritative absence; it
  is not generalized into a new snapshot framework.
- The plan adds no runtime config field, database entity, provider, scheduler, Combo-specific policy, or Advice
  strategy family.

## Architecture, coupling, and sequencing review

- Candidate policy stays in Candidate Engine; OpenD interval normalization stays in the application evidence owner.
- Sell Put, Covered Call, and Combo Funding Put retain their existing shared underwriting call path.
- Frozen snapshot scope results remain authority; AI and Brief consume a shared pure projection rather than duplicating
  policy or state.
- One slice is justified: committing only the evidence change or only the status change would leave a user-visible
  inconsistent intermediate contract. The allowed file set and stop condition bound the slice.

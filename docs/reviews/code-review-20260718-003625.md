## Findings

### S9-CR-01-未修复-中-PM 提供非法 period_cash_change 时会被当成字段缺失并静默派生

- **入口/函数**: `build_portfolio_cash_bridge -> _account_bridge`
- **文件(行号)**: `src/application/portfolio_cash_bridge.py:114-121`
- **输入场景**: PM `/analysis/cash-facts` 返回完整的 opening/external/ending cash，同时显式返回无法解析的 `amounts.period_cash_change`（例如字符串 `"unknown"`）。
- **实际分支**: `_money_or_none(...)` 对非法数值返回 `None`，随后代码进入“字段未提供”的派生分支。
- **预期行为**: 缺失的可选字段可以从余额派生；但显式提供且非法的上游事实应 fail closed，返回 structured unavailable/partial，而不是被解释为缺失。
- **实际行为**: 桥会从期初、外部现金流和期末现金派生期间变化，并可能返回 `status=ok`，从而掩盖 PM contract/data corruption。
- **直接证据**: `src/application/portfolio_cash_bridge.py:115-118` 无法区分 key absent 与 key present-but-invalid；`_money_or_none` 会吞掉解析错误并返回 `None`。
- **影响**: 上游现金事实格式错误可能静默通过并被呈现为已对账的现金桥。
- **建议改法和验证点**: 先检查 `"period_cash_change" in amounts`；若存在但无法解析则返回 `portfolio_cash_period_change_invalid` unavailable。增加显式非法值回归，同时保留字段缺失时的余额派生测试。
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中

### S9-CR-02-未修复-中-桥接证据遗漏 v1 报告级 valuation/fee evidence_fact_ids

- **入口/函数**: `build_portfolio_pnl_bridge -> _metric_evidence`；`build_portfolio_cash_bridge -> _option_cash_evidence`
- **文件(行号)**: `src/application/portfolio_pnl_bridge.py:234-250`；`src/application/portfolio_cash_bridge.py:247-264`
- **输入场景**: `option_performance_report` 返回真实 v1 扁平 metric envelope，并在顶层 `quality.evidence_fact_ids` 中记录 selected valuation mark、fee/source 等事实 ID。
- **实际分支**: 两个 helper 只尝试读取兼容性的 `metric.quality.evidence_fact_ids`；真实 `DecimalAmountEnvelope.to_dict()` 只输出 metric 级 `status/missing/fx_fact_ids`，而报告级 evidence IDs 来自 `PeriodPerformance.quality`。
- **预期行为**: 作为跨系统桥的审计 evidence 应保留 v1 报告所选事实 IDs，便于证明 cutoff、valuation、FX 和 fee basis。
- **实际行为**: `option_*_evidence.evidence_fact_ids` 在真实报告上恒为空，即使 report 顶层已有 IDs。
- **直接证据**: `domain/domain/performance/models.py:240-247` 的 metric envelope 不输出 `evidence_fact_ids`；`domain/domain/performance/engine.py:365-372` 把它们放在报告级 quality；S9 helpers 在 `portfolio_pnl_bridge.py:247` 和 `portfolio_cash_bridge.py:260` 只读 nested metric quality。
- **影响**: 金额正确但桥输出丢失关键审计链，无法从 bridge payload 回溯 selected valuation/fee facts。
- **建议改法和验证点**: 从 `report.quality` 读取并保存 `report_quality`/`evidence_fact_ids`，同时保留 metric `fx_fact_ids`；增加 PnL/cash 回归证明报告级 IDs 被透传且不会改变金额可用性判断。
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中

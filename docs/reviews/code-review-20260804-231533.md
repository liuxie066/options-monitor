## Findings

### DR4-01-未修复-中-health physical-endpoint inventory 的 host key 未规范化，大小写差异会重复计数并丢失 Telnet 绑定

- **入口/函数**: `healthcheck` -> account OpenD endpoint inventory -> canonical quote endpoint insertion -> legacy readiness projection
- **文件(行号)**: `src/application/agent_tools/healthcheck_impl.py:575-590, 606-618, 633-653, 727-784`; `src/application/account_config.py:325-343`
- **输入场景**: account broker binding 使用 host `LOCALHOST` 或 `QUOTE.local`，effective symbol fetch 使用大小写不同但等价的 `localhost` 或 `quote.local`，port 相同；account endpoint 还可配置非默认 Telnet port。
- **实际分支**: broker resolver 会把 binding host 规范化为小写，但 health 的 `opend_endpoints` inventory 仍直接用 `runtime_plan.futu_host` 原始大小写拼 key。canonical quote route host 已规范化为小写，因此 `opend_endpoints.get(quote_key)` 查不到 account row，quote doctor回退 Telnet `22222`；随后 quote insertion 又创建一个小写 key 的第二 row。循环里的 `endpoint_is_quote` 使用 lowercase comparison，两个 row 都被识别为同一 quote capability并各自生成 legacy endpoint check。
- **预期行为**: physical endpoint inventory 应在唯一 owner 处用与 route/broker resolver 相同的 normalized `(host, port)` key；同一 endpoint 只产生一个 legacy compatibility check，并保留 account row 的 Telnet metadata。
- **实际行为**: 同一 OpenD 可出现两个 `opend_readiness_<endpoint>` checks；quote failure 会增加重复 critical count/warning，违反 typed child 不重复扩大 legacy counts 的契约；quote doctor还可能探测错误 Telnet port并产生虚假 Telnet warning。
- **直接证据**: health lines 575-590 保留原始 host并直接构造 key；lines 606-618 用 canonical lowercase key查 Telnet；lines 633-641 在 exact-key miss 时新增 row；lines 649-653 又通过 lowercase判断两个 row 都是 quote endpoint；broker binding lines 331-343 已证明该系统的 canonical host语义是 lowercase。
- **影响**: health summary count、warning 和 Telnet evidence 对大小写等价配置不稳定，监控可能重复告警或报告错误 2FA/Telnet 状态；物理 dependency 计数不再可信。
- **建议改法和验证点**: 构建 `opend_endpoints` 时立即将 host strip+lower，并让 key、stored host、quote lookup和 typed check sanitizer全部复用同一 normalized endpoint helper；同 key 合并 accounts并保留非空 Telnet metadata。新增 regression：broker `LOCALHOST` + quote `localhost` 只调用一次 quote doctor、使用 account custom Telnet port、只生成一个 physical endpoint legacy check，quote failure只贡献一次 endpoint failure。

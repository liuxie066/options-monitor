## Findings

### CR-S1-01-未修复-中-Direct PeriodRequest bypasses conditional-field validation

- **入口/函数**: `normalize_period(PeriodRequest(...))`
- **文件(行号)**: `domain/domain/performance/period.py:130-134` and `68-94`
- **输入场景**: an internal caller constructs `PeriodRequest(period="month", month="2026-06", year=2025)` or `PeriodRequest(period="mtd", month="2026-06")` directly rather than using `from_mapping`。
- **实际分支**: `normalize_period` sees an existing `PeriodRequest` and skips `PeriodRequest.from_mapping`, so fields unrelated to the selected period are silently ignored。
- **预期行为**: the approved S1 contract and design doc state that extraneous period-specific fields fail closed regardless of construction path。
- **实际行为**: contradictory input normalizes successfully, making validation depend on which constructor path the caller happened to use。
- **直接证据**: conditional-field validation exists only in `from_mapping` (`period_fields - relevant`), while `normalize_period` only invokes it for non-`PeriodRequest` inputs。
- **影响**: later legacy/service callers can pass contradictory period state that appears accepted; public/parser parity can drift。
- **建议改法和验证点**: add a shared `PeriodRequest.validate()`/normalization helper invoked by both `from_mapping` and `normalize_period`; add direct-dataclass tests for extraneous fields and invalid kind。
- **修复风险（低/中/高）**: 低。
- **严重程度（低/中/高/严重）**: 中。

### CR-S1-02-未修复-中-Normalized duplicate currencies silently overwrite money

- **入口/函数**: `DecimalAmountEnvelope.__post_init__`
- **文件(行号)**: `domain/domain/performance/models.py:226-230`
- **输入场景**: caller supplies two syntactically distinct keys that normalize to the same currency, e.g. `{"usd": 1, "USD": 2}`。
- **实际分支**: both keys normalize to `USD`; the second assignment overwrites the first in `normalized`。
- **预期行为**: money facts must never be silently dropped; the domain should reject ambiguous duplicate canonical currency keys (or explicitly aggregate under an owned rule)。
- **实际行为**: the envelope reports only `2.000000`, losing the first amount without diagnostic。
- **直接证据**: loop assignment `normalized[normalize_currency(currency)] = quantize_money(amount)` has no collision check。
- **影响**: a malformed adapter input can under/overstate activity, cash or PnL while still returning `observed` quality。
- **建议改法和验证点**: reject a second source key resolving to an existing canonical currency; add a regression test for `usd` + `USD` and keep deterministic sorting for valid maps。
- **修复风险（低/中/高）**: 低。
- **严重程度（低/中/高/严重）**: 中。

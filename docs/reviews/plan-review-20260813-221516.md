## Final incremental review

### P3A-PRR-01 — S1/S2 sequencing — pass

S1 changes persistence/publication mechanics under the unchanged full oracle:
additive schema, generations, exact diff DML, fingerprints, heads, and trusted
reads. Checkpoint mode remains disabled. S2 then factors the shared full/tail
transition and updates the semantic manifest/digest in the same slice; a head
cannot remain trusted across the new implementation fingerprint without a new
full-oracle publication. S3 alone adds checkpoint runtime. Every boundary can
therefore stop without making a cache necessary for correctness, and the order
matches the accepted Phase 1 expand-and-verify contract.

### P3A-PRR-02 — rotation without persisted cadence counters — pass

Every checkpoint boundary is the last seed/rotation boundary. The already
required bounded strict-tail stream is therefore the complete cadence interval;
the runtime counts its rows and canonical bytes while applying it. It writes no
counter or checkpoint row between rotations, advances the boundary on rotation,
and never sums the prefix. Threshold constants are part of the checkpoint
schema, so a cadence change invalidates old rows. No redundant mutable state or
hidden O(E) work remains.

### P3A-PRR-03 — close history and public-field parity — pass

Current source uses the full-oracle `close_event_ids` vector to locate only its
last member, and the physical public row stores the scalar
`last_close_event_id`. The plan freezes the resumable schema with no
`close_event_ids` member while retaining scalar last-event facts and aggregate
economics. Full historical `ProjectionResult` keeps the complete list. Field-
level serialization assertions, repeated-partial-close space tests, final-row
parity, and emit-then-evict tests make this codegen-exact.

### P3A-PRR-04 — implementation fingerprint closure — pass-with-risk

The manifest guard resolves absolute/relative first-party imports with Python
AST, walks the graph to a fixed point, and requires exact discovered-set/edge
classification. Unlisted dynamic imports and unresolved/new edges fail. Sorted
path plus path/file length framing and raw bytes close ambiguity; the digest is
computed once per process and transactions use cached equality only. The
remaining human choice is whether a discovered file is semantic or explicitly
nonsemantic; that decision is visible, reasoned, CI-checked, and fails toward
conservative re-acceptance rather than silent omission.

### P3A-PRR-05 — retained-row fingerprint capacity — controlled residual

The frozen flat account fingerprint remains streamed O(L_a) for changed
accounts. The accepted fixture has a hard combined <=500-ms activation gate;
failure is `not_ready`. The mandatory `retained_lots_10x` run records
rows/bytes/wall/CPU and `retained_lots_10x_guarantee=false`, emitting a capacity
warning rather than silently promising or relaxing a new scale boundary.
Post-activation telemetry and explicit deactivate preserve correctness. A
Merkle/normalized alternative is deferred until measured evidence justifies a
new contract.

### P3A-PRR-06 — mixed atomic-batch idempotency — pass

Before mutation, the runtime looks up only submitted ids. Existing events reuse
their stored immutable `raw_payload.cash_conversions` before canonical-byte
comparison; exact matches cause no replay, generation, lot/head, or rotation
write. New ids alone receive new conversions and enter the strict ordered tail.
The plan freezes same-id conflict and mixed existing/new ordering regressions,
including the assertion that only new events cause DML.

## Open questions

No blocking design or user-choice question remains. Implementation must stop at
the slice gate if tests disprove state sufficiency, exact parity, atomic
publication, source-manifest closure, or any frozen time/space bound; it may not
relax the contract in code.

## Residual risks

1. Changed-account flat fingerprinting remains O(L_a). It is controlled by the
   accepted hard gate, explicit 10x no-guarantee evidence, telemetry/deactivate,
   and a later measured planreview destination.
2. Semantic versus nonsemantic classification of a machine-discovered source
   dependency remains a reviewed human decision. Exact graph closure prevents
   silent file omission; conservative raw-byte identity forces re-acceptance.
3. Global event generation still writes O(A) heads. The accepted account-fanout
   wall/CPU/allocation hard gate remains binding; failure returns the design to
   per-account partition planreview.
4. Void/repair/special Combo identity-membership and explicit rebuild paths
   remain force-full O(E). They are inventoried and measured separately and are
   never counted as fast-path success.
5. Zero-diagnostic v1 gating may reduce liveness if warnings become common. It
   fails safely to the full oracle with reason telemetry; warning-aware bounded
   state requires a later design.

Every residual is controlled in this work unit or assigned to a named later
review/operational boundary. None is unclassified.

Pass. Runtime Status formatting remains in `runtime_status_cli.py`; CLI adaptation remains in `observability_ops.py`; generated lifecycle policy remains in `service_deploy.py`. No domain/infrastructure dependency inversion is introduced.

Pass. The revised plan preserves structured diagnostics, bounds the journal-specific view, uses systemd's native one-shot runtime control, and avoids a shell pipe, new logging file, or global retry redesign.

Pass. One small journal mode and one optional renderer parameter address the observed sources. Trade-intake lifecycle and launchd timeout parity are deliberately not coupled to this work unit.

## Findings

### F1-未修复-中-Combo inventory adapter can discard snapshot-only identity and top-level expiry structure
- **入口/函数**: `run_close_advice` → `_apply_yield_enhancement_combo_economics` → `_combo_inventory_input`
- **文件(行号)**: `src/application/close_advice_runner.py:1523-1540`
- **输入场景**: An open option lot is correctly recognized as a Combo leg through `strategy_snapshot`, but one or more of `strategy`, `leg_role`, `strategy_group_id`, or `expiry_structure` is present only in the snapshot/top-level expiry field rather than the exact top-level keys copied by the adapter.
- **实际分支**: Leg evaluation uses `resolve_yield_enhancement_position_role`, which searches snapshots, but inventory construction receives raw top-level strategy fields only and does not pass `expiry_structure` at all.
- **预期行为**: The same persistent metadata that classifies the leg must feed the group inventory, including snapshot fallback and explicit expiry structure.
- **实际行为**: `build_option_group_inventory` may skip an opaque legacy group entirely (`missing_group_inventory`) or default a diagonal group to `same_expiry`, producing `same_expiry_mismatch` and a false `review_required`.
- **直接证据**: `_combo_inventory_input` copies `pos.get("strategy")`, `leg_role`, and `strategy_group_id` directly and omits `expiry_structure`; the leg resolver uses `_first_position_strategy_field`/snapshot lookup.
- **影响**: Valid persisted diagonal groups can lose group advice after restart or on older snapshot-shaped context rows.
- **建议改法和验证点**: Resolve snapshot fallbacks in `_combo_inventory_input`, pass `expiry_structure`, and add a snapshot-only diagonal fixture.
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中

### F2-未修复-中-Active group action ignores the already-authoritative Call action
- **入口/函数**: `synthesize_combo_yield_group_close_advice`
- **文件(行号)**: `domain/domain/close_advice.py:943-963`
- **输入场景**: Equal-quantity active Combo where Put advice is `close_put_keep_call` while the existing long-Call evaluator says `sell_call_take_profit` or `sell_call_salvage`; or Put says hold while Call says sell.
- **实际分支**: The helper requires one Call action but never consumes its value; it derives `combo_group_action` only from the Put action.
- **预期行为**: Group post-processing must preserve and reconcile both authoritative leg actions.
- **实际行为**: It emits `close_put_keep_call` even when the Call leg says sell, or `hold_active_combo` even when the Call leg says sell; it may also add `close_both_optional` instead of reflecting that both evaluators already recommend closing.
- **直接证据**: `normalized_call_actions` is cardinality-checked at lines 946-947, then unused; action selection at lines 948-955 reads only `put_action`.
- **影响**: Additive group advice can contradict the leg advice it claims to preserve, creating ambiguous operator guidance.
- **建议改法和验证点**: Map the Put hold/close × Call hold/sell matrix to deterministic group actions (`hold_active_combo`, `close_put_keep_call`, `sell_call_keep_put`, `close_both`) and only emit optional close-both when the Call evaluator says hold.
- **修复风险（低/中/高）**: 中
- **严重程度（低/中/高/严重）**: 中

### F3-未修复-中-Combo economics silently treats unavailable transaction fees as zero
- **入口/函数**: `_apply_combo_group_fields`
- **文件(行号)**: `src/application/close_advice_runner.py:1620-1645`
- **输入场景**: Current quotes are priced, but `calc_futu_option_fee` fails or cannot support the lot, causing `_apply_buy_to_close_fee` to add `fee_calc_unavailable` without a `close_fee`/`sell_to_close_fee`.
- **实际分支**: Call fee aggregation falls back to `0.0`; Put `realized_if_close` remains the pre-fee evaluator result; the group still reports `combo_cost_basis_status=ok` and may emit `close_both_optional`.
- **预期行为**: Unknown fees must remain unknown for combined economics; the system must not publish a complete net figure by assuming zero.
- **实际行为**: Net Combo economics are overstated and labelled complete despite the existing data-quality flag.
- **直接证据**: The fee lambda ends with `(safe_float(row.get("close_fee")) or 0.0)` and no check for `fee_calc_unavailable`; `_apply_buy_to_close_fee` explicitly marks that failure path.
- **影响**: Financial output can claim a computable group net/action under incomplete cost evidence.
- **建议改法和验证点**: If any participating row has `fee_calc_unavailable`, retain leg/group action classification but suppress group economics/optional close-both with an explicit economics status; add a fixture.
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中

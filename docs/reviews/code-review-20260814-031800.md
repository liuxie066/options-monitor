## Finding re-review

### S2-DR-01 — fixed

Transitions now carry the accumulator's scalar `previous_close_event_id`.
Adjust folding no longer infers semantic close history from arbitrary public
snapshot fields. The new regression proves a snapshot with a legacy
`last_close_event_id` but no applied close advances `last_action_at` on adjust
exactly like the unchanged full oracle.

### S2-DR-02 — fixed

The application publication state stores only the two-field open baseline for
auto-close metadata per active lot. A close restores that baseline before
overlaying the current close fields. Bootstrap fields therefore survive an
ordinary close, while a prior expire-close override is still removed. Canonical
round-trip, duplicate-key rejection and non-aliasing are covered.

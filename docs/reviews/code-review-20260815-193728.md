3. **`ret != 0` 时 `data` 为错误字符串**（`open_quote_context.py:318-330` docstring 与实现），实现 `raise RuntimeError(data)`（`futu_gateway.py:1032`）再走 `_raise_mapped`→`_map_error`→`classify_opend_error`，`str(RuntimeError)` 保留 provider 文案，2FA/auth/rate-limit/transient 映射保留（测试以 `RuntimeError("rate limit")` 断言 `FutuGatewayRateLimitError`）。

## Assumptions tested

1. A single canonical strategy scan can update successful current independently from ordinary delivery.
2. Fixed targets and half-hour candidate targets can share one scheduler without a second scanner or sender.
3. Daily Brief is the sole scheduled ordinary-notification renderer; Compact/Legacy cannot be restored by configuration.
4. Deprecated `notifications.daily_brief.enabled=true|false` values are compatibility inputs only and have identical routing behavior.
5. Manual/force reliable scans may update successful current but cannot create an ordinary envelope, resolve the provider route, or advance alerted/fixed delivery state.
6. Multi-market state may remain market-qualified while combined outbound returns a terminal fail-closed result.
7. Delivery-only retry replays an immutable envelope and cannot refresh broker facts, revisions, current, or message text.
8. Rollback can be performed safely only by stopping the scheduler and rolling back a compatible code/version/state set, not by enabling a parallel Compact path.

## Review lenses

- **Architecture boundary review**: scheduler owns target identity; account execution returns attempted targets; repository owns revision/current/delivery state; renderer owns human projection; the existing scheduled delivery adapter remains the sole provider boundary.
- **Best-practice review**: durable-before-send ordering, exact idempotent replay, explicit ambiguity, fail-closed pipeline/multi-market handling, and read-only query boundaries are specified with focused regression coverage.
- **Optimal-solution review**: reusing the existing 10-minute wake-up, scheduler, provider adapter, and one structured snapshot is materially simpler than adding a candidate timer, second renderer switch, or separate outbox service.
- **Overengineering review**: the plan explicitly rejects new frequency keys, a second scanner/sender, a renderer framework, a database/outbox service, and retention work without measured pressure.
- **Overcoupling review**: notification type is derived after the shared scan; candidate identity, successful current, delivery confirmation, and presentation remain independently owned rather than encoded in Markdown or scheduler text.

3. Long provider outages can accumulate exact fixed envelopes; retry remains bounded to the valid delivery window and unresolved items require audit/operator handling.
4. Historical v1 state cannot reconstruct fixed-target confirmation facts that were never persisted; migration must remain evidence-conservative.

## Adversarial Review

### Input and scope boundary

- Hidden `None` defaults are no longer exposed to or injected by Copilot.
- Explicit invalid/null input is preserved and rejected instead of being silently repaired.
- A valid explicit period removes only irrelevant model-supplied period fields.
- Fixed scene scope is applied last, so model input cannot override channel-owned account,
  symbol, month, or reference-year constraints.
- A conflicting fixed month remains fail closed; the normalizer does not erase it.
- An omitted account remains omitted and therefore means all matching accounts.

### Financial ownership and conservation

- Top-level realized gross/net remains the combined canonical result.
- Pure-option realized metrics are reduced only from allocation/missing-realization facts.
- Assigned-stock realized metrics are reduced only from generation-time assigned-stock facts.
- Assignment option realization remains option PnL; settlement and sale fees affect stock net
  once; settlement principal and sale proceeds remain cash rather than profit.
- Assigned-stock summary no longer uses shared source-event IDs to infer ownership, removing the
  collision that could pull option realization into stock PnL.
- The added reconciliation tests prove combined realized equals option realized plus
  assigned-stock realized for gross and net.

### User-visible contract

- The deterministic answer exposes period kind, date range, period status, and actual account
  scope before reporting values.
- Period total, combined realized, option realized, assigned-stock realized, premium activity,
  option cash, fees, settlement principal, stock-sale proceeds, assignment activity, and evidence
  gaps are visibly separate.
- Native-currency formatting keeps two decimals, including sub-unit fees.
- The exact production questions `7月 mtd 的期权收益` and `我写的是mtd` are covered. The P1
  evaluator rejects generic-analysis fallback, natural-month substitution, and implicit narrowing
  to `lx`.

### Stability and boundaries

- The normalizer is an optional `AgentTool` hook, so unchanged tools retain their existing
  execution path.
- Domain code still owns financial classification; Copilot and the renderer consume the canonical
  result rather than recomputing it.
- No new ledger schema, migration, write path, configuration key, or parallel income module was
  introduced.
- Repository dependency boundaries remain valid with zero production-module cycles.

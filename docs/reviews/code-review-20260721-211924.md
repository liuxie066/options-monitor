## Intent and contract alignment

The change introduces the approved narrow `render_receipt()` helper and moves only shared Receipt presentation into it:

- shared H1: `# OM · 回执 · <account>`;
- explicit receipt family: `类型｜成交` or `类型｜持仓维护`;
- caller-selected status;
- ordered flat fields;
- empty-section omission and multiline flattening.

No Receipt DTO, registry, template DSL, provider branch, sender, retry layer, persistence layer, or runtime switch was added.

## Adversarial path review

### Trade intake receipt

Entry path: `send_trade_intake_receipt()` -> `build_trade_intake_receipt_message()` -> existing delivery adapter.

Verified:

- send eligibility, duplicate/unconfirmed retry logic, route resolution, timeout/exception normalization, command/confirmation classification, and provider-local errors are unchanged;
- applied, unresolved, projection-verification failure, and assigned-stock ambiguity status decisions remain in the trade caller;
- action, symbol, contract, quantity, price, premium cashflow, time, projection, target-position verification, ledger, Combo Yield relation-pending warning, diagnostic reason, and deal ID retain their previous order and conditionality;
- assigned-stock candidates retain caller ordering, confirmation-before-write wording, next-step instruction, and final deal ID position;
- missing optional values are still omitted or rendered as the existing explicit `-`, not synthesized by the shell.

### Position-maintenance receipt

Entry path: `send_auto_close_receipt()` -> `build_auto_close_receipt_message()` -> existing delivery adapter.

Verified:

- dry-run/applied/partial/full-failure/noop status selection remains in the maintenance caller;
- broker, grace period, result counts, timestamp, completed items, error rows, and 6/5-row truncation counts are preserved;
- receipt identity, business-date keying, dedupe, unconfirmed retry, attempt count, persisted state, route selection, and provider error propagation are outside the shell and unchanged;
- completed and failure sections preserve order and are omitted only when their caller-owned row list is empty.

- **实际分支**: `run_cc_lp_variant` 返回 summary，但**不调用** `combo_pairs_sink_fn`；候选只写 `cc_lp_candidates.csv`

- **建议改法和验证点**: `run_cc_lp_variant` 增加 `combo_pairs_sink_fn` 参数，候选 rows 转 dict 后调用；测试断言 snapshot 含 CC+LP 候选

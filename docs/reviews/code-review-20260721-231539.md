## Change Intent

Preserve both accepted contracts after `main` introduced channel-aware mobile-flat notification rendering:

1. one canonical scan pipeline at fixed report points and valid half-hours;
2. full fixed reports at `09:40`, valid whole hours, and `15:50`;
3. immediate candidate alerts at valid half-hours, with fixed reports winning when both conditions hold;
4. manual/force scans update successful current snapshots without ordinary delivery side effects;
5. latest/day/revision query remains read-only;
6. user-facing output is compact mobile-flat Markdown and includes cash total, option-opening funds, candidate capacity, reminders, and explicit strategy/pipeline failure language.

## Adversarial Failure Pass

Checked the following counterexamples against code and tests:

1. **Fixed point and new candidate simultaneously**: fixed report wins; no second candidate alert is prepared.
2. **Half-hour pipeline failure**: no normal no-candidate message is emitted; failure artifact is retained and the scan target is committed.
3. **Fixed-point pipeline failure**: explicit `fixed_failure` envelope is rendered; successful current is not advanced.
4. **Manual or force scan with a new candidate**: successful current may advance, but candidate state, envelope, and provider send remain absent.
5. **No-send mode**: snapshot/candidate observation state may advance as designed, but no delivery envelope or confirmation is created.
6. **Existing retryable candidate envelope plus a later scan**: the exact envelope is preserved; a new mutable replacement is not silently substituted.
7. **Unknown funds**: rendered as unavailable, never fabricated as zero.
8. **Candidate alert**: positions are intentionally suppressed, while candidate-specific funds/capacity/reminders remain visible.
9. **Query aggregation with a missing scope**: available sections remain readable and a partial warning is explicit; delivery state is unchanged.
10. **Mobile formatting regression**: final fixed/candidate/failure/query projections contain no blockquotes, nested lists, or merge markers.

## Adversarial failure pass

- **Normal path**: first full persists immutable revision/current/run/shared/diff and returns a content-bound full key; confirmed send advances one market pointer.
- **Retry/crash path**: same semantic full content reuses its key; changed content receives a different key; delta remains based on last confirmed revision rather than previous current.
- **Malformed/tampered state**: invalid current, pointer, missing revision, mismatched digest, wrong delivery kind/key and tampered full semantic digest all fail closed.
- **Concurrency**: account+market lock serializes revision/pointer state; shared-index lock serializes cross-market/account read-modify-write; stale completions cannot regress a newer pointer.
- **Multi-market**: account/shared/revision/current/delivery/run artifacts are market-qualified where collision is possible; rejection rows are filtered by symbol market.
- **Architecture/ownership**: domain normalization/ranking remains in domain; pandas and state I/O remain application-side; no notification Markdown parsing, new DB, queue, scheduler or provider adapter was introduced.

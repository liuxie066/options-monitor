### 2-未修复-低-隐私测试把匿名随机串中的账户字母片段误判为泄漏

- **入口/函数**: `test_completed_run_flows_through_to_brief_view()`
- **文件(行号)**: `tests/test_ai_decision_advice_orchestration.py:335-340`
- **输入场景**: `secrets.token_urlsafe()` 生成的合法匿名 `account_ref` 偶然包含字符序列 `lx`。
- **实际分支**: 测试只删除 JSON key 文本 `"account_ref"`，没有删除其随机 value，然后对整个序列化字符串做 substring 检查。

- **实际行为**: 匿名值如 `bvh6kOOt9281alxy` 会概率性触发失败，掩盖真正的隐私回归信号。
- **直接证据**: aggregate AI suite 首次运行因此失败；相同产品路径的其他断言均通过。
- **影响**: CI 产生随机红灯，降低隐私守卫可信度。
- **建议改法和验证点**: 从 payload 对象中删除合法 `account_ref` 字段后，再检查完整 JSON value `"lx"`，不要做裸 substring 匹配。

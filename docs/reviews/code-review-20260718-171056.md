### S2-01-未修复-[高]-普通非 Combo 策略会把空 attribution 错误降级为 partial

- **入口/函数**: `build_strategy_attribution()` -> `_build_topology()` -> `resolve_event_attribution()`
- **文件(行号)**: `domain/domain/performance/attribution.py::resolve_event_attribution`
- **输入场景**: 普通 Sell Put/Covered Call open event 带 `strategy=sell_put` 或其他非 Combo metadata，但没有 Combo group。
- **实际分支**: resolver 看到任意 strategy/role/group 后进入 incomplete 分支，并返回 `strategy_attribution_incomplete`。
- **预期行为**: 没有 Combo Yield group 的已证明 scope 应输出 observed empty attribution，不因其他策略存在而降级。
- **实际行为**: coverage 收集 issue，空 attribution 变成 partial。
- **直接证据**: `if not any(...): return None` 后直接判断 `strategy != combo_yield or not group_id` 并报 issue；没有先排除明确的其他策略。
- **影响**: 几乎所有现有非 Combo 报表产生无意义 partial，违反 additive compatibility。
- **建议改法和验证点**: 明确非 Combo strategy 且 group 不带 `combo_yield:` 前缀时返回无 attribution、无 issue；只有出现 Combo indicator 后才执行完整性检查。增加 observed-empty 非 Combo 测试。
- **修复风险**: 低
- **严重程度**: 高
- **Gateflow finding decision**: accepted
- **Re-review state**: 未修复

### S2-02-未修复-[高]-所有历史已关闭 group 会永久出现在后续期间报表

- **入口/函数**: `build_strategy_attribution()` group output loop
- **文件(行号)**: `domain/domain/performance/strategy_attribution.py::build_strategy_attribution`
- **输入场景**: Combo group 在 5 月已完全关闭，用户请求 6 月或后续月份报告。
- **实际分支**: topology 从全部 scoped events 建立，随后所有 ready group 无条件进入 `rows`，即使没有 period facts、没有 capital overlap且生命周期在期间前已终止。
- **预期行为**: all-event topology 只负责稳定 identity；输出必须限定为与请求期间相交或在期间拥有 canonical measurement 的 group。
- **实际行为**: 历史 group 带 lifetime funding snapshot 永久出现在每个后续报告，group_count 随历史无限增长，并可能产生空 PnL/资本误导。
- **直接证据**: `for group_id in sorted(groups)` 仅检查 `status == ready`，未检查事实、segment 或 `[group_open, group_terminal)` 与 period 的交集。
- **影响**: 月报/YTD payload 膨胀、期间 scope 错误、消费者可能把历史 funding snapshot 当本期活动。
- **建议改法和验证点**: 引入 period relevance predicate：有 period fact、capital overlap，或 group lifecycle 与 period 区间相交时才输出；完全在期间前终止或期间后才开仓的 group 排除。增加 prior-closed/future-open 测试。
- **修复风险**: 中
- **严重程度**: 高
- **Gateflow finding decision**: accepted
- **Re-review state**: 未修复

### S2-03-未修复-[中]-守恒证明缺少 period total gross/net

- **入口/函数**: `_conservation()`
- **文件(行号)**: `domain/domain/performance/strategy_attribution.py`
- **输入场景**: realized 与 opening/ending unrealized 单项各自守恒，但 period-total 组合公式或符号实现错误。
- **实际分支**: conservation 只遍历六个 base fact kinds，没有验证 `period_total_gross` 和 `period_total_net`。
- **预期行为**: accepted plan 要求逐项验证 realized、opening/ending unrealized 及 period total；period total 是跨期错配最关键的守恒信号。
- **实际行为**: reducer 的 `ending - opening + realized` 若回归，base facts 仍全部显示 observed conservation。
- **直接证据**: `_conservation()` 循环 `_PNL_BASE_KINDS`；period totals 仅存在于 group `_pnl_report()`。
- **影响**: 不能证明跨月总收益未错配，review green signal 不完整。
- **建议改法和验证点**: 由 attributed source facts独立计算 source period total，再与 groups 的 period total 比较，分别 gross/net、native currency、Decimal residual；partial source保持 partial。增加 opening/end valuation + realized 混合测试。
- **修复风险**: 中
- **严重程度**: 中
- **Gateflow finding decision**: accepted
- **Re-review state**: 未修复

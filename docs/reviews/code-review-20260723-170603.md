## Findings

### S2-DR-01 — 未修复 — 中 — 小额费用在收益报告中会被四舍五入为零

- **入口/函数**: `_render_option_performance()` -> `_performance_metric_text()` -> `_format_ccy_amounts()`
- **文件(行号)**: `src/application/assistant/renderer.py:736-744,827-834`; `tests/test_assistant_runtime.py:123-191`
- **输入场景**: 期权、指派结算或指派股票卖出费用包含小于一个货币单位的实际值，例如 `USD -0.35`。
- **实际分支**: 新增的收益现金流展示复用 `_format_ccy_amounts()`；该共享格式器使用 `:,.0f`，把 `-0.35` 渲染为 `-0`。现有回归只使用整数费用，因此无法发现该错误。
- **预期行为**: 收益报告中的实际现金和费用至少保留两位小数，使小额费用可见且可审计。
- **实际行为**: 非零费用显示为零，用户会误以为费用未发生，并导致净收益与展示明细难以核对。
- **直接证据**: `_performance_metric_text()` 在有原币金额时调用 `_format_ccy_amounts()`；该函数在第 831 行以零位小数格式化所有金额。
- **影响**: 直接破坏本 work unit 的“现金流和实际费用清晰可见”成功标准；不改变底层数值，但会产生误导性线上回答。
- **建议改法和验证点**: 为 option-performance 指标使用保留两位小数的专用原币格式器，不扩大修改其他报告的共享展示；将回归费用改为小数并断言精确出现 `USD -0.35`。
- **修复风险**: 低
- **严重程度**: 中
